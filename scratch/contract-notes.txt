Critical-finding discipline (skeptic pass)
=========================================
- findings_reassessment.json: each critical/high has reassessment
  fixed | needs_manual | deferred_ni with proof string.
- PACKAGE_STATUS: perfect ONLY if package has defining tests AND zero
  critical findings still needs_manual/still_open.
- Packages with unrevalidated criticals demoted to deferred with count.
- Permanent deferred: shells, Unity containers, PolygonBoolean NI, Cactus LCA NI.
- Revalidated fixed examples: edgeId=2 flow builders, SumSourceOutFlow,
  ulong BitCompress, StableMarriage scratch layout, DuJiao sieve-before-Get,
  Smawk row minima, Steiner masks, etc.
- Remaining needs_manual (~70 critical) live only on deferred packages —
  not claimed perfect.
